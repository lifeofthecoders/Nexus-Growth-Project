# NEXUS Growth // Full-Service Creative Production & Digital Agency

An award-winning, full-service creative engineering agency platform built with **Next.js 16 App Router**, **React 19**, **GSAP**, **Tailwind CSS**, and **Framer Motion**.

---

## ⚡ Integrated Capabilities & Services (11 Disciplines)

1. **Website Development** (`/services/web-development`)
   - Custom Next.js 16 + React 19 App Router architectures
   - Hardware-accelerated GSAP timelines and Lenis inertia scrolling
   - Sub-second First Contentful Paint (FCP < 0.40s) and 99+ Core Web Vitals
2. **AI Automation** (`/services/ai-automation`)
   - Atmospheric cybernetic dark-mode UI inspired by Eyepune
   - Signature cybernetic eye cursor tracking and interactive audit calculator
   - Autonomous multi-agent pipelines (LangGraph / CrewAI) & custom LLM infrastructure
3. **Branding & Design** (`/services/branding-design`)
   - Theatrical, editorial visual identity experience inspired by Unifiers of Japan
   - Dynamic character dossier selector (Nobunaga, Hideyoshi, Ieyasu)
   - Bespoke typography, kanji watermark aesthetics, and tone-of-voice foundations
4. **App Development** (`/services/app-development`)
   - Native iOS & Android architectures built on React Native & Expo SDK
   - Fluid 120Hz gesture physics, offline-first SQLite sync, and biometric authentication
5. **Graphic Design** (`/services/graphic-design`)
   - Brutalist, tactile, and editorial design collateral across digital and print touchpoints
6. **Google & Meta Ads** (`/services/google-meta-ads`)
   - High-ROAS paid media acquisition with server-side Meta CAPI tracking
7. **Social Media Management** (`/services/social-media-management`)
   - Algorithmic short-form video production, viral hook frameworks, and community growth
8. **Video Production & Editing** (`/services/video-production-editing`)
   - 4K cinematic brand films, motion graphics, and vertical retention social reels
9. **Copywriting & Content Strategy** (`/services/copywriting-content-strategy`)
   - High-conversion sales copy, landing pages, and automated lifecycle email flows
10. **SEO (Search Engine Optimization)** (`/services/seo`)

## 🛠️ Tech Stack & Architecture

- **Framework**: Next.js 16 (App Router with Turbopack)
- **UI Library**: React 19
- **Styling**: Tailwind CSS v4 + Neo-Brutalist & Decathlon tactile design system
- **Motion & Physics**: GSAP 3 (ScrollTrigger) & Framer Motion
- **Icons**: Lucide React
- **Typography**: Space Grotesk, Roboto Flex, Shippori Mincho, JetBrains Mono

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### 3. Production Build
```bash
npm run build
npm run start
```
